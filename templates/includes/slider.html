{% comment %} Reusable, accessible slider (carousel). Works without JavaScript: the track is a CSS scroll-snap strip that can be swiped, scrolled or moved with the arrow keys. static/js/slider.js adds arrows, dots, keyboard keys, mouse drag and (hero only) autoplay. Usage: {% include "includes/slider.html" with id="events" label="Upcoming events" items=events slide_template="includes/event_card.html" item_name="event" %} Class names are written out in full (never built from variables) so Tailwind keeps their styles. Options: variant = "cards" (default) | "hero" | "gallery" | "lightbox"; per_view = "4" for smaller cards; theme = "light" (default) | "dark"; autoplay = milliseconds per slide (hero only; never with reduced motion). `items` must be a list (the view converts querysets). Every slide is a labelled group ("2 of 5"). {% endcomment %}{% load rlm %}
